# 提示词管理

多套命名系统提示词，下拉切换，下一回合生效。

## 用法

1. 设置 → 提示词管理。
2. 在编辑框写正文，起个名字，点「另存为新模板」——同时会切到这一套。
3. 之后用顶部下拉切换。切换即写入 `active`，不需要保存按钮。
4. 「停用注入」把整段关掉，模板库留着。

## 注入位置

`systemPrompt.section({ order: 10300 })`，排在 DSH 自带段之后（部署人格后缀是 10200），也就是系统提示词最下面。`complete: true` 会用正文取代整份系统提示词，工具说明也一起没了，只在明确知道后果时用。

## 模板库存在哪

插件配置的 `config.templates`，一个 JSON 字符串：`[{"name":"编码","text":"……"}]`。配置本身落在 profile 的 `cordis.patch.yml` 里条目 `prompt-manager` 下。

## 也让 agent 切

`prompt_manager` 工具：`list` / `use` / `add` / `set` / `remove` / `on` / `off`。直接说「切到写作模板」也行。

## 边界

- 与其它注入插件共用系统提示词时，两段都会进上下文；用同一段位置 (order) 靠先后顺序决定，不会互相覆盖。
- 改 `order` 或 `complete` 需要重挂插件条目，改正文与 `active` 不用。
